# genz_looks

Things worth buying. Next.js + TypeScript + Tailwind (App Router).

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Add products
- Quick: go to /admin and fill the form (saved in your browser only).
- Permanent: add an object to `data/products.ts`, commit, push.

## Deploy
1. Push to GitHub.
2. On vercel.com: Add New → Project → import the repo → Deploy.
